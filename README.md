# Attributing Behavior in LLM Agent Trajectories

Official repository for the paper:

**Attributing Behavior in LLM Agent Trajectories:  
A Unified Benchmark and Annotation Framework**

This work introduces a unified benchmark and annotation framework for
trajectory attribution in large language model agents.

The benchmark covers:

- task-aligned actions
- unsafe actions
- safety refusals
- primary attribution components
- multi-step attack and execution chains

The current benchmark contains more than 1,300 annotated trajectories derived
from AgentDojo and the Stage and Canary settings of Agent3Sigma.

## Release Status

This repository is under active development.

The following resources will be released:

- benchmark data and annotations
- trajectory standardization utilities
- evaluation protocols and metrics
- attribution baselines
- reusable annotation skill

The reusable annotation skill is designed to support model-specific benchmark
construction by standardizing and annotating trajectories generated by new
agent models under a consistent attribution framework.
